Punto de partida

Qué es V4.1 Flash y por qué importa

Un agente son dos cosas: las herramientas (terminal, archivos, navegador, mensajería) y el modelo que piensa y decide qué hacer con ellas. Casi todos los agentes te dejan cambiar el modelo, y DeepSeek V4.1 Flash es ahora mismo de las opciones más interesantes por tres motivos:

  • Es abierto. Los pesos están publicados en Hugging Face con licencia MIT: puedes descargarlos, alojarlos donde quieras y usarlos en un negocio.
  • Está hecho para agentes. La versión de octubre (V4.1-Flash-1017) termina las tareas antes y responde más corto que la anterior, y sube con fuerza en las pruebas de agentes.
  • Es barato. Por API cuesta una fracción de lo que cuestan los modelos cerrados de primera línea. Los números, más abajo.

Además entiende imágenes, admite un millón de tokens de contexto (cabe un proyecto entero o cientos de páginas) y funciona con o sin modo de razonamiento.

Sobre «sin censura»

Lo que te da un modelo abierto es control: tú decides dónde corre, qué instrucciones de sistema lleva y quién ve tus datos. Lo que no cambia es el entrenamiento: el modelo trae sus propios límites de serie, lo uses por API o en tu servidor. Si alguien te promete otra cosa, desconfía.

Fase 1

La API key

01

Crea tu cuenta y recarga saldo

Entra en platform.deepseek.com, regístrate y añade saldo. DeepSeek funciona con prepago y descuenta de lo que hayas recargado. Para probarlo con un agente durante semanas, con unos pocos dólares sobra.

02

Genera la clave

En API keys, crea una nueva y cópiala en el momento: no se vuelve a mostrar.

Cuidado

La clave es dinero. No la pegues en chats, capturas ni repositorios. Si se te escapa, bórrala en esa misma página y crea otra.

03

Apunta los tres datos que vas a usar

Modelo
deepseek-flash. Ahora mismo lo sirve V4.1-Flash-1017.
Dirección, formato OpenAI
https://api.deepseek.com
Dirección, formato Anthropic
https://api.deepseek.com/anthropic

Esa doble dirección es la clave de todo: DeepSeek habla el mismo «idioma» que OpenAI y que Anthropic, así que cualquier agente pensado para GPT o para Claude puede usarlo cambiando solo la dirección y la clave.

Fase 2

En Claude Code

Es la vía más rápida y la que DeepSeek documenta oficialmente. Claude Code no cambia (herramientas, comandos, skills), pero el que piensa es DeepSeek.

04

Instala Claude Code, si no lo tienes

Necesitas Node.js 18 o superior y, en Windows, además Git for Windows.

npm install -g @anthropic-ai/claude-code
claude --version
05

Apúntalo a DeepSeek

# Mac y Linux. Sustituye TU_CLAVE por tu API key
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=TU_CLAVE
export ANTHROPIC_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-flash
export CLAUDE_CODE_EFFORT_LEVEL=max
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=786432
# Windows, PowerShell
$env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="TU_CLAVE"
$env:ANTHROPIC_MODEL="deepseek-flash[1m]"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-flash[1m]"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-flash[1m]"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-flash"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"
$env:CLAUDE_CODE_AUTO_COMPACT_WINDOW="786432"

Así todos los modelos que pide Claude Code (el principal, los subagentes y el rápido) van a deepseek-flash, con el millón de tokens de contexto activado.

Ojo con «Opus»

Si se te queda algún nombre sin cambiar, DeepSeek lo traduce solo: lo que empiece por claude-opus va a deepseek-v4-pro, que cuesta varias veces más, y lo que empiece por claude-sonnet o claude-haiku va a Flash. Por eso se fijan las tres variables.

06

Arranca y compruébalo

cd /ruta/a/tu-proyecto
claude
Bien

Claude Code arranca sin pedirte iniciar sesión en Anthropic y responde. En el panel de DeepSeek, el apartado de uso empieza a sumar tokens: esa es la prueba de que piensa DeepSeek.

Los export solo duran mientras esa terminal está abierta. Si quieres dejarlo fijo, pégalos al final de ~/.zshrc (Mac) o ~/.bashrc (Linux). Si vas a alternar entre Claude y DeepSeek, mejor guárdalos en un archivo aparte y cárgalo solo cuando quieras DeepSeek: source ~/deepseek.env.

Fase 3

En otros agentes

07

OpenCode: viene de serie

opencode → /connect → deepseek → pegar la clave → elegir Flash

DeepSeek recomienda OpenCode 1.18.30 o superior.

08

Cualquier agente que acepte un proveedor compatible con OpenAI

Hermes, OpenClaw, n8n, Cline y la mayoría de agentes tienen un apartado para añadir un proveedor propio («Custom endpoint», «OpenAI compatible»). Siempre piden lo mismo:

Base URL
https://api.deepseek.com, o https://api.deepseek.com/anthropic si el agente pide formato Anthropic.
API key
Tu clave de DeepSeek.
Modelo
deepseek-flash

Para comprobar la clave fuera del agente, esta llamada tiene que devolverte un saludo:

curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TU_CLAVE" \
  -d '{"model":"deepseek-flash","messages":[{"role":"user","content":"Hola"}]}'

Lo que cuesta

Precio en dólares por millón de tokens, según la página oficial de precios:

Horas valleHoras punta
Entrada que ya está en caché0,0030,006
Entrada nueva0,150,30

Las horas punta son de 01:00 a 04:00 y de 06:00 a 10:00 UTC, de lunes a viernes (en España, la madrugada y primera hora de la mañana). El resto del tiempo, fines de semana incluidos, se paga la mitad.

Por qué la caché importa tanto

Un agente reenvía una y otra vez el mismo contexto: instrucciones, archivos, historial. Lo que DeepSeek ya tiene en caché cuesta unas cincuenta veces menos que lo nuevo, así que en sesiones largas de agente la factura baja mucho más de lo que sugiere la tabla.

El paso siguiente

Ser independiente: los pesos abiertos

Usar la API es cómodo, pero sigues dependiendo de DeepSeek. Lo que hace distinto a este modelo es que los pesos están publicados en Hugging Face con licencia MIT. Eso abre tres caminos:

La API de DeepSeek para empezar

Lo de las fases 1 a 3. Barato y sin montar nada. Tus peticiones pasan por los servidores de DeepSeek.

Otro proveedor que lo aloje si te importa el control

Como los pesos son libres, otros proveedores de inferencia pueden servir el mismo modelo. Tú eliges dónde viven tus datos y, si uno falla o sube precios, cambias de proveedor sin cambiar de modelo ni de agente.

Tu propio servidor

Descargas los pesos y lo corres tú. Control total: nadie más ve nada.

Seamos realistas con el servidor propio

«Flash» no significa pequeño: son 552.000 millones de parámetros, y la guía oficial de inferencia lo reparte entre 8 GPU de servidor. No cabe en un portátil ni en un ordenador de sobremesa normal; es para alquilar máquinas con GPU o para una empresa con infraestructura. Para casi todo el mundo, la independencia real es la segunda opción.

A trabajar

Cinco tareas para estrenarlo

Copia cualquiera de estas peticiones en tu agente ya conectado a DeepSeek.

T1

Ordenar tus archivos

Revisa la carpeta Descargas, agrupa los archivos por tipo y por proyecto y propón una estructura de carpetas. No muevas ni borres nada hasta que te dé el visto bueno.
T2

Leer un documento larguísimo

Lee este contrato entero y dame mis obligaciones, los plazos, las penalizaciones y las cláusulas que me conviene negociar, citando el apartado de cada una.

Con un millón de tokens de contexto, el documento entra de una vez, sin trocearlo.

T3

Entender una captura o un gráfico

Te paso una captura del panel de ventas. Dime qué ha cambiado respecto al mes pasado y qué tres cosas debería mirar primero.
T4

Una herramienta a medida

Hazme una página web sencilla que calcule el presupuesto de un cliente a partir de horas de trabajo, precio por hora y materiales, con el IVA incluido. Que funcione abriendo el archivo, sin instalar nada.
T5

Investigar antes de decidir

Busca en internet cinco alternativas a [herramienta que pagas], compara precio y funciones en una tabla, enlaza la fuente de cada dato y dime cuál me recomiendas y por qué.

En Claude Code la búsqueda web funciona con DeepSeek: el agente decide cuándo buscar y DeepSeek no cobra la búsqueda, solo los tokens del modelo.
