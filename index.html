Integración

Incrustar un recurso

Cada recurso acepta ?embed=1. En ese modo se quitan la barra superior, la marca de agua y el margen exterior, y el documento pasa a medir exactamente lo que ocupa su contenido.

Alto fijo · una línea

Suficiente si el contenedor ya tiene una altura definida.

<!-- basta con esto -->
<iframe src="…/recursos/vast-ollama.html?embed=1"
        style="width:100%;height:900px;border:0"
        loading="lazy"
        title="Vast.ai paso a paso"></iframe>

Alto automático · recomendado

El recurso publica su altura al contenedor con postMessage cada vez que cambia. El contenedor sólo tiene que escucharlo.

<iframe id="racks"
        src="…/recursos/vast-ollama.html?embed=1"
        style="width:100%;height:600px;border:0;display:block"
        loading="lazy"
        title="Vast.ai paso a paso"></iframe>

<script>
  addEventListener('message', function (e) {
    var d = e.data;
    // comprueba también e.origin si el contenedor es público
    if (d && d.source === 'racks-resource' && d.type === 'resize') {
      document.getElementById('racks').style.height = d.height + 'px';
    }
  });
</script>
Parámetros

?embed=1 activa el modo incrustado. Añade &bg=transparent para que el fondo lo ponga el contenedor, y &id=loquesea si incrustas varios recursos en la misma página y necesitas distinguir de cuál viene cada mensaje de altura.

Si el contenedor prefiere preguntar

Enviar {source:'racks-embed', type:'request-height'} al iframe hace que responda con su altura en el acto. Útil tras abrir un acordeón o cambiar de pestaña en el contenedor.

Sistema

El estilo, en corto

Los tokens salen del panel de producción. Están en assets/racks.css y son la única fuente: si el panel cambia un color, se cambia ahí y todos los recursos se mueven a la vez.

Tipografía
Inter para todo; monoespaciada del sistema para etiquetas, código y cifras.
Radio
0,5 rem en tarjetas y paneles; 0,25 rem en fichas y botones pequeños.
Firma
Rejilla de puntos de 24 px y la R gigante en #151515 abajo a la derecha.
Acento
Naranja único. Un elemento activo por bloque, nunca dos compitiendo.

Para escribir un recurso nuevo: copia recursos/plantilla.html, que trae ya montados los bloques disponibles — pasos, avisos, tablas, código con botón de copiar, fichas y controles. La referencia larga está en ESTILO.md.
